What is this Project?

The brief description is simply a design of the PID control system of the physical phenomenon called magnetic levitation. Put simply, it makes a mass float in a stable position in mid air using an electromagnet.

Magnetic Levitation Control

This is the final result

Objective

Control the position of the levitating object.

Workflow

  1. Decide what the objective is. This is the first and most important step.
  2. Find out which materials are available and needed.
  3. Understand the physical system.
  4. Reverse engineer the physics and the sensors.
  5. Design the control system.
  6. Implement the control system in a mechanical setup.

Physical System

Physical Concepts

This is the mathematical model of the physical system.

The system is unstable, so we need to design a control system to stabilize it.

We can treat it as a black box and obtain the transfer function, or tune the PID manually.

In this case we'll fit the curves and use that knowledge to tune the PID by hand.

Sensor Curve

Reverse Engineering The Sensor Response

The sensor response is not well defined, so we need to reverse engineer it.

We measure the sensor response to a known input and fit a curve to the data.

That curve gives us the function that maps distance to voltage.
